# LTFA v0.1.0

Release date: not published

LTFA v0.1.0 was accepted locally as the first offline model compiler preview.
It loads one explicitly rooted LTFA DSL v1 model, resolves bounded local
includes, validates and normalizes the model, and renders deterministic human,
JSON, or DOT output.

## Included

- native C++17 core and one-shot `ltfa` CLI
- bounded DSL v1 lexer, parser, and model-root-safe include resolver
- typed model validation and deterministic normalization
- human summaries, `ltfa.model/v1` JSON, and DOT output
- descriptor-backed human and `ltfa.command-help/v1` JSON help
- stable `LTCLI-001` usage diagnostics and `ltfa.cli-error/v1` JSON errors
- MIT licensing and CMake install support

## Explicitly Not Included

The accepted v0.1.0 candidate did not implement path search, impact analysis,
articulation or bridge detection, SPOF detection, failure propagation,
observation diagnosis, live probing, command execution, monitoring integration,
plugins, databases, or network access.

## Candidate Verification

The candidate test matrix passed Release (16/16), ASan/UBSan (14/14),
LeakSanitizer (14/14), and ASan/UBSan with parser seed replay (15/15). No
v0.1.0 tag or remote release reference was created or published.

## Public Contract

- CLI Contract: 1
- DSL: LTFA DSL v1
- model JSON: `ltfa.model/v1`
- command help JSON: `ltfa.command-help/v1`
- CLI error JSON: `ltfa.cli-error/v1`
- process statuses: 0 success, 2 usage, 3 input, 4 validation, 5 output

See `docs/decisions/0001-bootstrap-boundary.md` and
`docs/decisions/0002-cli-contract-and-first-release-boundary.md` for the
accepted historical boundary.
