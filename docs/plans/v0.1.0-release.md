# v0.1.0 Release Preparation Plan

Date: 2026-07-29

Status: candidate accepted

Owner direction selected the MIT License and authorized the remaining `v0.1.0`
release-preparation work. This plan is separate from the residual offline-MVP
PERT and does not modify or claim completion of its Slice 2 tasks.

## Candidate Scope

The candidate contains only the accepted Slice 1 offline model compiler, the
CLI Contract 1 implementation, and release packaging:

- LTFA DSL v1 local parsing and bounded include resolution
- model validation, deterministic normalization, and human/JSON/DOT output
- descriptor-backed text and JSON help and stable CLI errors
- project version `0.1.0`
- MIT licensing and release notes
- CMake installation of the CLI and distribution documents

It excludes all analysis, live observation, probing, network, command
execution, plugin, database, daemon, and production-integration behavior.

## Ordered Gates

1. `R010_LICENSE_VERSION`: add the MIT text and set all generated and tested
   version surfaces to `0.1.0`.
2. `R010_PACKAGE`: add release notes, install the executable and distribution
   documents, and exercise the installed executable from an isolated prefix.
3. `R010_VERIFY`: pass Release, ASan/UBSan, LeakSanitizer, fuzz-seed, static and
   runtime offline-boundary, CLI-contract, and optional Graphviz checks.
4. `R010_IMMUTABLE_CANDIDATE`: create one narrow commit and rerun or confirm
   candidate evidence against that exact commit.
5. `R010_ACCEPT_TAG`: record candidate acceptance before tag creation.
6. `R010_PUBLISH`: create and publish `v0.1.0` only under separate explicit
   authorization, then verify every requested remote reference.

Gates 1 through 5 are complete in the commit containing this acceptance record.
Gate 6 remains open. A local version change, passing test, or candidate
acceptance does not imply publication.

## Verification Commands

```bash
cmake --preset release
cmake --build --preset release
ctest --preset release

cmake --preset asan-ubsan
cmake --build --preset asan-ubsan
ctest --preset asan-ubsan

cmake --preset lsan
cmake --build --preset lsan
ctest --preset lsan

cmake --preset fuzz-seeds
cmake --build --preset fuzz-seeds
ctest --preset fuzz-seeds
```

The install-tree test owns only
`<preset-build-directory>/install-smoke`, recreates that prefix, verifies the
installed license and documents, and exercises `--version`, `--help`, and one
offline JSON model compilation.

## Publication Restart Condition

Resume at `R010_PUBLISH` only after an explicit tag/publication decision. Create
and publish the `v0.1.0` tag from the accepted candidate commit, then verify each
requested remote reference against that exact commit.
