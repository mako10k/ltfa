## Build and fixture profile

- Measurements use the committed `release` CMake preset and the dynamically linked ELF output.
- Correctness evidence uses the committed Release, ASan/UBSan, and LeakSanitizer profiles separately;
  sanitizer output is never used for performance comparison.
- The benchmark driver is `EXCLUDE_FROM_ALL`, not installed, and has no product CLI surface.
- Generated fixtures live below `build/benchmark-fixtures` and remain uncommitted.
- The model is a deterministic acyclic dependency graph. The observation file is deterministic
  probe history with a fixed analysis reference time and no live data, secret, or network input.
