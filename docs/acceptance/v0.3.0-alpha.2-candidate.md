- PERT criterion receipts and task completion remain pending exact owner approval; hosted CI success
  does not grant that approval implicitly.
- The binary remains `0.3.0-alpha.1`; Issue #2 does not authorize release metadata, an alpha.2 tag,
  GitHub Release, package publication, or stable promotion. Release-candidate preparation may
  follow acceptance as a separate governed action.
- Markdown prose remains review-maintained and protected by focused synchronization tests rather
  than generated completely from C++ descriptors.
- The aarch64 semantic run is a portability validation, not a new five-run performance acceptance
  sample. Previously accepted two-tier performance evidence remains unchanged.
- Active probes, producer integration, network access, command execution, plugins, databases,
  daemons, secret retrieval, implicit clocks, automatic repair, and unrestricted-ID leakage remain
  outside the candidate.
